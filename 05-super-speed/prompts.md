# 05 · Super Speed — prompts

**Context:** You joined Rook two weeks ago as PM on Dispatch.
Release 4.2 shipped on 12 August, just before you arrived, and
landed badly. You've spent three sessions finding out what went
wrong: the two piles of feedback that didn't agree, the numbers that
hid four people inside an average, and the code that settled it —
the shorter timeout is what did it.

At the end of the session, type wrap up, and Claude Code saves the
prompts you wrote yourself below — not the starter prompt — updates
CLAUDE.md, and saves your work to GitHub. By Module 6 this file is a
prompt library built from your own questions.

---

### 1.
Read 05-super-speed/director-request.txt  and explain to me what the director wants to see

### 2.
check my brief against her ask

### 3.
this brief is hard to read. let's simplify to have just one or two sentences per section. Bring in the key data (tables are fine). Rewrite it in language that is at the 5th grade level.

### 4.
let's organize the brief as follows. 1-executive overview 2-decisions we need from Helen 3-open items, decisions we need from other teams 4-problem we're solving for and why now 5-ideal state and plan to get there 6-supporting data 7-open questions with assigned owners

### 5.
pretend you are Helen. give this brief a read and provide feedback. to make sure i have better confidence as you are playing helen I want you to do so using multiple models. don't come back to me until the different helen's are aligned and you have clear guidance on what changes we need to make to this brief.
